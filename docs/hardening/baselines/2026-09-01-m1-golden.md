## Detection controls

Focused tests pass 4/4 and prove:

- a bootstrap result deliberately changed from `442` to `443` is localized to
  case index 12 (`compiler-square`), event index 0, channel `value`, byte 3;
- the same perturbation produces an independent cross-stage divergence against
  the seed route;
- a zero-byte output cap is reported as the named `resourceCaps` channel while
  the underlying program value remains unchanged;
- a normal run leaves the corpus byte-identical.

The controls are runner injection and a temporary copied corpus. They do not
special-case production execution or weaken expected observations.

## Disposition

M1 is complete over the stages and profiles declared above. It does not claim a
general compiler, shared interpreter/compiler state, macro-expansion hashes,
reader/printer properties, structured recoverable errors, or GC. M2 is the next
active milestone: deterministic reader/printer and expansion properties plus
malformed-input/resource-bound fuzz evidence.
