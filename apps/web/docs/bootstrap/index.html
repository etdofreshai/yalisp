Bootstrap

Let Lisp
grow the seed.

The checked-in boot.lisp program is evaluated by the WAT seed at startup. It adds macros and reusable functions in YALISP itself, making the difference between Seed and Bootstrap directly executable.

The current real bootstrap adds cond, defn, let, boolean macros, structural equality, and list functions such as map, filter, and reduce. It does not yet include a YALISP compiler.

02 / Compiler status

Interpreter first.
Compiler later.

Lispish has a later Lisp-written compiler and runtime JIT, but those layers are not part of this minimal YALISP port yet. The gallery therefore marks JIT and AOT unavailable and publishes no invented comparison numbers.

The next compiler milestone must port a checked-in Lisp compiler stage, verify compiled output against this interpreter, and only then expose measured JIT or AOT modes on the site.
