Bootstrap

Let Lisp
grow the seed.

The checked-in boot.lisp program is evaluated by the WAT seed at startup. It adds macros and reusable functions in YALISP itself, making the difference between Seed and Bootstrap directly executable.

The real bootstrap adds cond, defn, let, boolean macros, structural equality, and list functions such as map, filter, and reduce. The separate compiler.lisp milestone loads after this bootstrap.

03 / Compiler status

Interpreter first.
Compiler bounded.

YALISP now loads a small Lisp-written compiler after the bootstrap. It supports exactly one parameter and nested binary integer +, -, and * expressions; every other form remains interpreted.

Read the compiler boundary or use the Playground to measure the verified interpreter, JIT, and AOT paths on the same supported workload.
