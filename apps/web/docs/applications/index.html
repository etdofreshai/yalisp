Applications use YALisp’s interfaces for low-level computation, portable system services, and document-and-event interaction.

01AssemblyLow-level WebAssembly computation02System interfacePortable access to host services03DOMPortable documents and events

The intended application bootstrap is a proposed DOM-level helper that creates one root surface, wires lifecycle and input, and selects the platform binding. Browser builds would use the native DOM; SDL and bare-metal builds would initialize YALisp’s lightweight SDL-backed document tree and surface. Its name, signature, ownership rules, and additional-root behavior remain to be defined, and no such helper is implemented yet.

The Examples gallery makes that boundary concrete: Hello World runs through the current seed with its complete browser and CLI hosts shown, while Pong, Breakout, and Asteroids execute complete displayed TypeScript modules through a shared portable Canvas contract. The games are not presented as an implemented YALISP DOM, SDL, or Game Runtime binding.
