YALisp architecture

Foundation

Grow the language
from a small seed.

YALisp begins with the smallest WebAssembly-backed seed that can read and run enough Lisp to construct the next layer. Each stage builds the tools that make the following stage possible.

01

Seed

A minimal WebAssembly foundation supplies the primitive values, memory, control flow, and reader support required to begin.

02

Bootstrap

That seed runs a small Lisp environment with enough forms and functions to define the language in the language.

03

Compiler

The bootstrap is used to create the YALisp compiler: it reads YALisp forms, lowers them through the foundation, and produces runnable output.

04

Applications

With the compiler available, YALisp can build applications against Assembly, System Interface, and DOM without requiring a large separate runtime.

The purpose is not to hide the implementation. The seed stays deliberately small and inspectable; the bootstrap and compiler are YALisp code that can grow with the language.
