Foundation / Compiler

Compiler

One language.
Three execution paths.

The current YALISP path is interpreted: the WAT seed evaluates forms before and after loading the Lisp bootstrap. JIT and ahead-of-time compilation are planned, not implemented.

01

Interpreted · available

The checked-in WAT seed reads and evaluates forms directly for the Playground and bootstrap.

02

Just-in-time · planned

No YALISP JIT exists yet. A future port must prove compiled results match the interpreter before this mode becomes available.

03

Ahead-of-time · planned

No YALISP AOT compiler or artifact exists yet. The site publishes no simulated timings for this mode.

Only interpreted execution is currently verified. The Playground identifies JIT and AOT as unavailable until real implementations and equivalence tests are checked in.
