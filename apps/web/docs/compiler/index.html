Foundation / Compiler

Compiler

One language.
Three execution paths.

The YALisp compiler grows from the bootstrap and selects the path that fits the program and platform.

01

Interpreted

Read and evaluate forms directly for bootstrapping, the REPL, and exploration.

02

Just-in-time

Compile eligible code while it runs to accelerate interactive programs.

03

Ahead-of-time

Build a chosen program before it runs for predictable deployment and startup.

These modes are complementary: the same YALisp code can move from interpretation to runtime compilation or a prebuilt artifact.
