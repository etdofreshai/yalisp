Foundation / Seed

Seed

The smallest
executable core.

The YALISP seed is a real WebAssembly interpreter assembled from checked-in WAT. It reads S-expressions, evaluates a deliberately small language, and prints actual results in the browser.

This implementation is derived from the verified M9 seed in Lispish commit c78a2be. YALISP keeps that seed boundary: one host.write import, a fixed four-page memory, and no simulated results.

01 / Supported surface

Enough Lisp
to grow Lisp.

values

Small tagged model

Integers, booleans, nil, symbols, strings, pairs, closures, macros, and primitives live in WebAssembly memory.

forms

Seven evaluator forms

quote, if, lambda, macro, define, set!, and begin are implemented by the seed.

primitives

Lists, numbers, and strings

Cons cells, arithmetic, comparisons, type predicates, and a small string surface are available before bootstrap.

The seed does not provide garbage collection, recoverable errors, modules, system or DOM access, or compilation. Each gallery run starts a fresh bounded instance.
