This Playground assembles no pretend output. Each example runs in WebAssembly generated from the checked-in WAT seed, optionally after that seed evaluates the checked-in Lisp bootstrap.

The implementation is derived from the verified M9 seed in Lispish commit c78a2be. Read the Seed and Bootstrap explanations for the exact boundary.

Current boundary

Measured honestly.
Limited explicitly.

The current YALISP runtime is the interpreter generated from bootstrap.wat plus boot.lisp. Guarded reader, type, and heap failures report their kernel diagnostic and discard that run. JIT and AOT are shown as unavailable because their Lispish implementations have not been ported and verified here. The benchmark reports only real interpreter work performed after you tap Run.
