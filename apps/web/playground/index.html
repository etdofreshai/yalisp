This Playground assembles no pretend output. Each example runs in WebAssembly generated from the checked-in WAT seed, optionally after that seed evaluates the checked-in Lisp bootstrap.

The implementation is derived from the verified M9 seed in Lispish commit c78a2be. Read the Seed and Bootstrap explanations for the exact boundary.

Current boundary

Measured honestly.
Limited explicitly.

The full gallery remains interpreted by the seed generated from bootstrap.wat plus boot.lisp. The compiler milestone is narrower: compiler.lisp lowers one-parameter integer expressions built from binary +, -, and *. The benchmark compares that exact supported workload through the interpreter, a fresh browser JIT module, and the compiler-produced AOT artifact. It does not imply that arbitrary gallery programs compile.
