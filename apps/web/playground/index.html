Executable Seed + Bootstrap

A real REPL.
In the browser.

Use the transcript like a small console: load an example, edit it, evaluate it, then keep building on the same live Seed or Bootstrap session. Every result comes from WebAssembly generated from the checked-in WAT seed.

A session is deliberately bounded. Switching interpreter stages starts a new session; a guarded kernel error discards only that session, and the next evaluation starts fresh. Read the Seed and Bootstrap explanations for the exact boundary.

The full gallery remains interpreted by the seed generated from bootstrap.wat plus boot.lisp. The compiler milestone is narrower: compiler.lisp lowers one-parameter integer expressions built from binary +, -, and *. The benchmark compares that exact supported workload through the interpreter, a fresh browser JIT module, and the compiler-produced AOT artifact. It does not imply that arbitrary gallery programs compile.
