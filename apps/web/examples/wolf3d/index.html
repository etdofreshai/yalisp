05 / Original data

Wolf3D map data,
decoded in Lisp.

The application declares the original MAPHEAD.WL6 and GAMEMAPS.WL6, the host hands over their bytes, and Lisp does the rest: ID_CA.C’s map header structures, then Carmack and RLEW expansion of both planes of the first level. What you see is that decode drawn one tile per block — a readout of the original bytes, not a rendered level.

Arrow keys step one tile along the original’s dirtype facing, refusing solid tiles by SetupGameLevel’s own rule. The originals are commercial data files and are not part of this repository: without them mounted, the page says so instead of showing something invented. The next gate is VSWAP and VGAGRAPH, which carry the real palette and wall textures, and then the raycaster.

Authenticity boundary. TypeScript fetches the two declared files, hands their bytes to the evaluator, forwards declared input, and puts a returned framebuffer on a canvas. Every offset, tag, expander, and tile rule below is Lisp, ported from the original C.
