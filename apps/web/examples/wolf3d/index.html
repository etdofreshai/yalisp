Wolf3D,
running in YALISP.

Twenty-three source-shaped Lisp modules own the game loop, actors, rendering, menus, intermission, saves, and original audio timing. The generic browser host mounts the nine declared original inputs, forwards controls, presents the indexed framebuffer, and plays the Lisp-exported PCM and OPL register streams.

Use the arrow keys or WASD to move, Space or E to use, and Control to attack. The commercial originals are never committed or shipped in the production bundle: run npm run mount:assets --workspace @yalisp/web -- wolf3d for local development. If any required input or the OPL host is unavailable, the application reports that boundary instead of substituting invented content or silence.

Authenticity boundary. TypeScript moves declared bytes, input, framebuffer pixels, and audio output across the host boundary. Game rules, decoding, simulation, presentation state, and audio events remain Lisp-owned.
